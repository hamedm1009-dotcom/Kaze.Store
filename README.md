# KAZE Store — Starter

واجهة أولية لمتجر ملابس رجالي باستخدام HTML وCSS وJavaScript Modules.

## الهوية البصرية
- خلفية داكنة: `#101310`
- أبيض مائل للرمادي للنصوص: `#f5f7f3`
- أخضر فاتح للأزرار والعناصر المهمة: `#b9f56b`
- تصميم Mobile-first، مع دعم RTL للعربية وLTR للإنجليزية.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `css/style.css`: التصميم المتجاوب.
- `js/app.js`: تبديل اللغة والتثبيت وتسجيل Service Worker.
- `locales/`: ملفات الترجمة.
- `manifest.webmanifest`: تعريف PWA.
- `sw.js`: كاش أساسي وواجهة Offline جزئية.
- `firestore.rules`: قواعد مغلقة افتراضيًا لحين إعداد قواعد Firebase الكاملة.
- `firebase-messaging-sw.js`: ملف تمهيدي غير مفعّل.

## النشر
يمكن رفع الملفات إلى مستودع GitHub ثم الذهاب إلى Settings > Pages واختيار Deploy from a branch ثم `main` و`/(root)`. يدعم GitHub Pages HTTPS بعد اكتمال النشر.

## تنبيه
هذه نسخة واجهة أولية وليست متجرًا جاهزًا للبيع. لا توجد بعد قاعدة منتجات حقيقية أو تسجيل دخول أو سلة طلبات أو لوحة أدمن. لا تفتح صلاحيات Firestore العامة. ستضاف قواعد تفصيلية واختبارات أمان عند إعداد Firebase.
